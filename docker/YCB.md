# YCB objects

OpenArm 1.0 / 2.0 のどちらでも、シーンGUIの **YCB オブジェクトライブラリを開く** から操作できます。
検索で `mug`（取っ手付きマグ）、`plate`（平皿）、`bowl`（ボウル）などを選び、指定位置へ配置・ランダム配置・削除を使ってください。各種類1個、複数種類を同時に配置できます。X/Yはworld座標のメートル、向きは度。高さは机上に自動設定されます。

収録範囲は [YCB公式ダウンロードカタログ](https://ycb-benchmarks.s3.amazonaws.com/index.html) の `objects.json` に載る **103項目（サイズ・部品バリエーションを含む）** です。YCB-Videoの21種類だけではありません。布など、公式3Dカタログに存在しない物理キットの品目は含みません。

- 93項目: 公式スキャンを使用。
- 2項目: `072-g_toy_airplane`、`072-h_toy_airplane` のスキャン台座断片を除去して再構成。近似であることをGUIに表示。
- 8項目: ワイングラス、鍵、樹脂ボルト、樹脂ナット、ビー玉c/e/f、タイマーは、公式データが空・表面なし・著しく破損しているため明示的な代替形状。公式の完全なCADモデルではありません。

公式ページ自体も透明物体などのメッシュが不完全であることを説明しています。代替物体の寸法の由来・推定箇所は各 `model.json` の `note` に記録しています。特にビー玉c/e/fの直径と鍵の輪郭は推定です。

## 物理とMoveIt

表示は公式テクスチャ付きメッシュ（テクスチャ512px）。接触は凸分解メッシュの集合で、MoveItにも同じ接触メッシュを送ります。マグの取っ手・器の内側を一つの凸包で塞ぐ構成にはしていません。ただし有限の凸分解なので細部には誤差があります。

非表示時は描画・接触・重力を無効化します。物体の配置は机上範囲と他物体／ロボットとの干渉を確認し、失敗時は元の配置を維持します。机の非表示は全物体を削除してから行ってください。既存の把持デモは配置済みのYCBを片付けて直方体を準備します。**任意YCBを自動把持する認識・把持計画コードは今回の追加には含みません。**

全項目は剛体です。スポンジの変形、鎖の関節、ハサミの開閉、組立品の分解、ルービックキューブの回転、ガラスの透明光学特性は再現していません。重量のある品目や薄い品目をOpenArmが必ず把持できるという意味ではありません。

質量は [YCB ICAR 2015論文 Table I](https://www.ri.cmu.edu/pub_files/2015/7/ICAR-FINAL.pdf) で対応が取れる項目に使用。個別部品など質量が不明な項目は「外接箱体積×500 kg/m³、1–1000gに制限」の推定で、GUIに明示します。重心は外接箱中心、慣性はその箱の一様密度近似、摩擦も共通値です。精密な力学同定済みのYCBモデルではありません。

## 配布と開発

`docker/vendor/ycb/catalog.json` が両ロボットで共通のカタログです。各フォルダに表示メッシュ、接触メッシュ、テクスチャ、変換・寸法・SHA-256を記録した `model.json` を収録しています。Dockerイメージにも含めるため、構築後の配置操作にはインターネット不要です。

`oa-code` の `environment/docker/app/ycb_assets.py`、`ycb_panel.py`、`dynamic_objects.py`、`object_scene_sync.py` が実装です。コア環境の変更は通常どおり `./start.sh` で再ビルドしてください。

ROSサービスは既存物体と共通です。例: `/openarm/objects/ycb_025_mug/set_enabled`（SetBool）、`/openarm/objects/ycb_025_mug/place`（SetParametersAtomically: x,y,yaw、yawはラジアン）。公式IDのハイフンはROS名ではアンダースコアに変換しています。

帰属・ライセンス・変換条件は `docker/vendor/ycb/ATTRIBUTION.md` を参照してください。

MuJoCoビューアの同期頻度は標準30 Hzです。大きなカタログを読み込んだ状態で画面更新が物理計算を圧迫しないようにしています（描画・計算速度はPC構成に依存）。
